## What's new in v1.3.0

### New features
- **Undo Refund** — a new "Refund Details" card appears on an expense once a refund has been recorded. Each refund listed has an "Undo Refund" button that removes it, mirroring the existing "Undo Transfer" flow
- **Smart Rules — dynamic THEN actions** — the THEN card now works exactly like the WHEN conditions card: tap "Add action", pick a type from a dropdown, fill in the value, remove with ×. Multiple actions per rule are supported

### Improvements
- Smart Rules dropdowns (Field, Operator, Action Type) now show a checkmark and accent highlight on the currently selected option
- Home screen header now shows `Arth · अर्थ` with a middle-dot separator

### Bug fixes
- "Record a Refund" button is now hidden once an expense is fully refunded (was always visible for realized expenses)
- Expense no longer shows "Refunded" or "Partial Refund" status after the refund credit has been deleted
- Transfer details (From / To accounts) now correctly appear when viewing a CC bill payment that was marked via a repayment forecast
- Transfer details also correctly appear when viewing a credit that was reclassified as a transfer
- Amounts that round to zero (e.g. a ₹0.001 floating-point residual) no longer display as −₹0
- Devanagari "अर्थ" on the home screen now matches the English "Arth" in font size and weight
- Smart SMS Templates (user-created templates) are now correctly included in backups — previously the `source_version` column was missing from the restore whitelist, causing every template row to be silently dropped on restore
