Goals are things you're saving towards over time — a trip, a car, an emergency fund, retirement. The Goals tab has three building blocks:

- **Life Milestones** — named targets with a deadline and an amount. "Down payment ₹15L by Mar 2028."
- **Investment Buckets** — specific financial instruments you contribute to. A mutual fund, a recurring deposit, a chit fund.
- **Yearly Plan** — what you plan to save and spend for the current fiscal year.

Buckets can optionally link to milestones — a bucket's growth then counts towards the milestone's progress.

## Where to find them

**Goals tab** (bottom nav).
- "Life Milestones" section → all active milestones with progress bars.
- "Investment Buckets" section → all buckets with current vs target.
- "Yearly Plan" card → planned vs actual this FY.
- "YoY Comparison" link → side-by-side with last FY.

## Create a milestone

1. **Goals tab → Life Milestones → +**.
2. Fill: name, target amount, deadline, category (retirement / house / trip / emergency / education / other).
3. Optionally link one or more investment buckets.
4. Tap **Save**.

The milestone's progress bar fills as linked buckets grow and as you log direct milestone contributions.

## Create an investment bucket

1. **Goals tab → Investment Buckets → +**.
2. Fill: name, instrument type (mutual fund, FD, RD, chit, PPF, EPF, stocks, other), target amount (optional), FY.
3. Optionally link to a milestone.
4. Tap **Save**.

## Log a contribution

Three ways:

**1. From the bucket detail** — Goals → tap bucket → **+ Contribution** → enter amount, date, notes → Save.

**2. From a transfer to a demat account** — When you create a transfer that lands in a demat account, Artha auto-asks: is this **Fund** (idle cash with the broker) or **Portfolio** (already invested)? If Portfolio, pick a bucket; the contribution is auto-logged.

**3. Automatically from a matched SIP SMS** — if the merchant matches a bucket's configured SIP merchant, Artha creates the contribution on approval.

## Goal vs budget — what's the difference?

They're separate systems; you typically run both at the same time.

**Budget** — caps what you **spend**.

- Monthly window.
- Resets each calendar month.
- Scoped per category.

**Goal** — targets what you **save**.

- Multi-year window.
- Accumulates across months / years.
- Scoped per milestone or bucket.

## Common situations

**"I have a mutual fund SIP — how do I track it?"**
Create a bucket named after the fund. Set target if you have one. Each month's SIP is a contribution; you can log manually or let a matched SMS auto-create it.

**"Delete a transfer that I assigned to a bucket."**
Safe — when you delete an account transfer that had demat-target set, Artha reverses every side-effect: the contribution row is removed, the bucket's total rolls back, and any linked milestone's saved total updates.

**"Retirement / EPF tracking?"**
Create a bucket per EPF / NPS / PPF account. Log employer + your contributions as they land. Artha's SMS parser recognizes EPF/pension contributions from the major processors.

**"Can a goal have no target amount?"**
Milestones need a target amount. Buckets don't — a bucket can just track "how much have I contributed" for open-ended savings.
