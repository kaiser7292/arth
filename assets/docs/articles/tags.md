**Tags** are coloured labels you attach to expenses for grouping and filtering that goes beyond Arth's built-in category system. Use them for projects, events, trips, or any cross-cutting theme — "Goa trip", "Home renovation", "Work reimbursable" — that spans multiple categories.

## Creating a tag

1. Open **Settings → Master Data → Tags**.
2. Tap the **+** button.
3. Enter a **name** for the tag.
4. Choose a **colour** from the available palette.
5. Tap **Save**.

Tags are immediately available to attach to expenses.

## Tagging an expense

On the Add or Edit Expense screen, tap the **Tags** field. A list of your tags appears; tap one or more to select them. An expense can have multiple tags. The selected tags appear as coloured chips on the expense.

## Viewing tagged expenses

On the Transactions tab, use the filter options to filter by one or more tags. Only expenses with all the selected tags will appear (AND filter). This makes it easy to see the total spent on "Goa trip" regardless of whether expenses were food, transport, or accommodation.

## Usage count

The tag list in Settings shows how many expenses each tag is attached to. This helps you see which tags are active and which you may want to clean up.

## Editing and deleting tags

**To rename or recolour a tag** — tap it in Settings → Tags. Change the name or colour and save. The updated tag immediately reflects on all expenses it is attached to.

**To delete a tag** — tap the trash icon next to it. Deleting a tag removes it from all expenses it was attached to. This cannot be undone, but the expenses themselves are not affected — only the tag association is removed.

## Common situations

**"I want to track a work trip separately."** Create a tag like "Work trip May 2025". Attach it to all expenses during that trip — flights, hotels, meals, transport. Then filter by that tag to see the total cost and get a reimbursement breakdown.

**"I want to separate reimbursable expenses."** Create a "Reimbursable" tag. Add it to every expense your employer will pay back. Filter by the tag at month-end to see the total pending reimbursement.

**"Can I use tags instead of categories?"** Tags complement categories — they do not replace them. Categories drive budget tracking and insights; tags are a flexible layer on top for ad-hoc grouping.
