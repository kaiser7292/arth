**Payment modes** let you tag each expense with how you paid — UPI, cash, credit card, debit card, net banking, or any custom method you define. This makes it easy to see your spending split across payment channels and to reconcile your accounts.

## Built-in payment mode types

Arth ships with a set of standard types:

- **UPI** — payments via any UPI app (PhonePe, GPay, Paytm, etc.)
- **Cash** — physical cash payments
- **Debit card** — card payments from your savings or current account
- **Credit card** — card payments charged to your credit card
- **Net banking** — NEFT, RTGS, or IMPS transfers
- **EMI** — purchases converted to equated monthly instalments
- **Cheque** — payments by cheque
- **Wallet** — payments from a digital wallet (Paytm wallet, Amazon Pay, etc.)
- **Other** — anything that does not fit the above

## Managing payment modes

Open **Settings → Master Data → Payment Modes** to see all your payment modes.

**To add a custom mode** — tap + and enter a name and type. For example, you might add "GPay UPI" and "PhonePe UPI" as separate modes under the UPI type if you want more granular tracking.

**To rename a mode** — tap it and edit the name. The type cannot be changed after creation.

**To delete a mode** — tap the trash icon. Arth only allows deletion if the mode has no usage — if it is already attached to expenses, it cannot be deleted. Remove it from all expenses first, or keep it and just stop using it.

## Tagging an expense with a payment mode

On the Add or Edit Expense screen, tap the **Payment Mode** field and select from the list. The payment mode is optional — you can leave it blank if you do not need this level of tracking.

## Where payment mode data appears

Payment mode is shown on individual expense detail screens. The Insights tab includes a payment mode breakdown so you can see the spending total attributed to each method for a given period.

## Common situations

**"I can't delete a payment mode."** The mode is still attached to one or more expenses. You would need to edit each expense and change the payment mode before deletion is allowed. If the mode is no longer in use, it is harmless to leave it — it simply won't appear in new entries.

**"I want separate UPI modes for different apps."** Add each app as a custom payment mode under the UPI type. This lets you filter or group by app in insights without losing the higher-level UPI category grouping.
